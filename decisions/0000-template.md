# 0000. Template

This file is not a decision. It is the shape every record in this directory
takes, kept as a file rather than as a description, so that a new record starts
by copying something that is already right instead of by reading a rule and
approximating it. Copy it to the next free number, name the copy after the
question, and replace this paragraph with what is at stake and why the question
could not be left open.

The four headings below are required and they stay in this order. Two further
headings are used only where they apply. `## What was measured` holds the
commands and their output where the decision turns on a number, and it goes
before `## The decision` when the number is what forced the answer.
`## What this record does not decide` names a neighbouring question a reader
would otherwise assume this record had settled. `README.md` beside this file
states the numbering, the naming and the supersede rule in full.
