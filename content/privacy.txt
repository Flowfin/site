Privacy

description: What happens to a request for a page on this site, what is kept,
  and which of those statements a check refuses a page for breaking.

This site is a set of files that a build produced and a host serves as they
are. There is no account, no form, no database and nothing of this project's
running on a server, so there is nothing here that could hold anything about a
reader.

A page saying that is worth what a reader can check, and a reader can check
none of it from the outside. So every statement below carries what stands
behind it. A statement in the first list names the check that refuses a page
breaking it, and a name that no check answers to reds the gate rather than
staying here. A statement in the second list is a promise and says so, with the
issue that would turn it into the first kind. The last list is what is true
anyway and is not promised at all.

checked: No page this site produces asks a reader's browser to fetch a script.
  [page-fetches-no-script]

checked: Nothing a page this site produces reaches for comes from a domain this
  project does not control, so no font service, no icon service, no analytics
  and no embedded player is told that somebody opened a page here.
  [output-references-no-domain-outside-the-allowlist]

checked: No cookie is set and nothing is written into either browser storage
  area. [page-touches-no-browser-storage]

checked: No page here carries a handler written onto an element, so nothing on
  a page runs in answer to what a reader does with it.
  [page-carries-no-inline-handler]

promised: There is no form, no field and no other route by which a reader can
  send anything from a page here. [#50]

promised: No page needs scripting to be read, which is wider than either of the
  two checked statements about scripting above. What is refused today is a page
  fetching a script and a handler written onto an element, and a script element
  carrying its code inside the page is refused by nothing yet. [#50]

promised: What the checks above read is the names a page would have to spell.
  A page reaching the same interface through a value none of those spellings
  finds is refused by nothing, and what would see it is a browser loading every
  produced page and reporting what it did. [#50]

residual: Whatever host answers for these files sees each request, which is the
  address it came from, what was asked for and when. Every host sees that much,
  this project does not decide what the host keeps, and this page does not say
  otherwise.

residual: Every checked statement above is about the bytes this build produced.
  What a reader's browser loads is whatever answers at the address, which can
  include something served beside these files that this repository never wrote,
  and nothing here reads that.
