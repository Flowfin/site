The repository holds the shape of this plugin and none of what it is for. What
it is meant to do is let a collection be described once as a rule about the
library, and then be filled and refilled from the library as it changes, so that
a collection is a standing question rather than a list somebody has to keep
adding to.

Before it is any use it will need a library large enough that maintaining a
collection by hand is the annoyance it exists to remove, and a way of writing a
rule that an operator can read back six months later and still understand.

What it does with data about a person is nothing: a rule is about titles and the
collection it fills is about titles. Nothing about it is meant to leave the host.
That is what the plugin is meant to do, and none of it is built yet.
