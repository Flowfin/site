The plugin lets somebody with an account ask the server for a title it does not
have, and gives the administrator a queue where those asks are answered rather
than a stream of messages somewhere else.

Before it is any use an administrator has to have somewhere a request can be
answered from, which is their own decision about how a library grows, and it has
to be clear to the person asking that a request is a question rather than an
instruction.

What it does with data about a person is keep who asked for what, which is a
record of somebody's interest in a title and is not nothing. It stays on the
operator's host.
